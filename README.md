# Beaki website

Public landing page for [Beaki](https://www.beaki.app), hosted for free with GitHub Pages.

The site is intentionally dependency-free: semantic HTML, responsive CSS and a small amount of vanilla JavaScript. Its product previews use fictional data and code-rendered mockups, so no user information or mobile screenshots are published.

## Local preview

Serve this directory from a local HTTP server and open `index.html`. Absolute asset paths require the site root to be the repository root.

## Deployment

GitHub Pages publishes the root of the `main` branch. The `CNAME` file binds the site to `www.beaki.app`; DNS for the apex and `www` is managed in the private Beaki infrastructure repository.
